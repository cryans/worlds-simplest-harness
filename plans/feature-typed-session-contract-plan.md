# Typed session contract — implementation plan

Branch: `typed-session-contract`. Requirements: `feature-typed-session-contract-requirements.md`.

Tick each box only once its **Verify** passes; don't start the next step until it does.

## 1. Spike: get an un-routed model into `/openapi.json` — **done**
- [x] Tested `responses={...}`, `openapi_extra`, and an `app.openapi()` override. **Winner: override.**
- [x] `responses={200: {"model": SseEvent}}` alone puts the members in `components.schemas` with the
      discriminator — but inlines the union on the operation and emits **no named `SseEvent`**.
      Wrapping `app.openapi()` to register `SseEvent` as a `oneOf` + `discriminator.mapping`
      schema makes it a named, importable type. Members must still be generated by a route with
      `responses={...}`, so the `/api/chat` entry stays.

**Spike result** (`openapi-typescript@7.13.0`, pydantic 2.14.1): emits
`SseEvent: SessionEvent | StatusEvent | ErrorEvent`, members get literal `type` fields, and
`tsc --strict` narrows correctly (`ev.session_id` ok on `session`, `ev.content` rejected on the
union). The mapping must list every member explicitly or narrowing degrades.

**Verify:** ✅ `SseEvent` present in `components.schemas`; generated TS narrows under `tsc --strict`.

## 2. Define the response models — **done**
- [x] Add `ToolStep`, `SessionTurn`, `SessionMeta`, `SessionList`, `SessionPayload` to `main.py`.
      Field names and types exactly as the design's model diagram; `error`/`incomplete`/`result`
      default to `None`/`False`/`None`.
- [x] `messages: list[dict]`, tool `args`/`result` stay raw (design: out of scope).

**Verify:** ✅ `SessionPayload` validates the 9-turn fixture **and** 17 real logs; `SessionMeta`/`SessionList`
validate all list entries.

**Finding:** `result: dict` was wrong — `manage_plan` returns a **string**, so real logs failed
`ValidationError`. Corrected to `dict | str | None` (the model matches the wire, not vice-versa).
The frontend's hand-written `BashResult` has the same bug: plan results render as `[exit undefined]`.
Step 7 must handle `string` results when importing generated types.

## 3. Return the models from the endpoints — **done**
- [x] `list_sessions()` and `get_session(...)` now declare `response_model=SessionList` /
      `SessionPayload` (FastAPI validates + serialises at the boundary).

**Verify:** ✅ `uv run pytest -q` → 32 passed.

**Plan correction:** the original wording ("`prepare_session` returns the model + no test edits +
32 passed") was contradictory — a Pydantic model is not subscriptable, so the 20+ direct
`prepare_session(...)` unit tests would go red. Split cleanly: step 3 types only the **API boundary**
(which is what generates the OpenAPI schema anyway); step 4 converts the internal function and the
unit tests together.
